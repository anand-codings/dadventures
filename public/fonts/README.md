# Fonts

Latin subsets of five open-source typefaces, bundled so the app needs no network connection. All are licensed under
the SIL Open Font License 1.1 and were downloaded from Google Fonts.

| File | Typeface | Used for |
|---|---|---|
| `big-shoulders-stencil-900.woff2` | Big Shoulders Stencil Display | the wordmark in the sidebar |
| `big-shoulders-display-900.woff2` | Big Shoulders Display | page titles in the header bar |
| `barlow-condensed-600/700.woff2` | Barlow Condensed | headings, navigation, step names |
| `dm-sans-var.woff2` | DM Sans (variable) | body text and buttons |
| `b612-400/700.woff2` | B612 | small labels and captions |

They are loaded by `../theme.css`.

The license and each typeface's copyright notice are in [`OFL.txt`](OFL.txt), which must stay with the font files.
